**学习目标：**掌握小红书选题方法，学会写出高点击率的标题，完成第一篇笔记的创作

**预计用时：**60分钟学习 + 45分钟实操

## 一、选题：先找需求，再写内容

90%的新手踩的第一个坑就是：想到什么写什么。爆款笔记的第一步永远是**逆向思考**——先搞清楚用户在搜什么，再决定你写什么。

### 1.1 搜索词库法：找到高需求低竞争的选题

#### 选题黄金法则

**用户搜索量高 + 优质内容少 = 最佳选题机会**

#### 第一步：打开小红书搜索框

在小红书APP顶部的搜索框中，输入与你领域相关的核心词（比如"职场沟通"、"读书方法"），注意观察搜索框下方自动出现的**联想词**。这些联想词就是用户真实在搜索的词，按热度排序。

#### 第二步：收集搜索词

把联想词全部记录下来，然后逐一搜索，观察搜索结果页：

| 判断维度   | 怎么看                             | 好选题的标准             |
| :--------- | :--------------------------------- | :----------------------- |
| 搜索量     | 搜索结果数量多（1万+篇）           | 说明有人搜               |
| 竞争度     | 前排笔记点赞量普遍低于500          | 说明优质内容不够，有机会 |
| 内容缺口   | 搜索结果中没有你擅长角度的内容     | 就是你的机会             |
| 评论区需求 | 大量用户在问"能详细说说吗""求推荐" | 说明内容需求未被满足     |

#### 第三步：用工具辅助验证

- **小红书站内搜索**：免费，最直接的数据来源
- **千瓜数据**（free.xiaohongshu.com）：查看关键词搜索指数和竞争度
- **5118**：查看跨平台搜索趋势
- **百度指数**：辅助判断话题热度趋势

### 1.2 选题方向清单

以下是知识干货类赛道中最容易出爆款的选题类型：

| 选题类型   | 举例                            | 适合人群     | 出爆款概率 |
| :--------- | :------------------------------ | :----------- | :--------- |
| 盘点推荐类 | 「35岁后必读的10本书」          | 所有领域     | 高         |
| 步骤教程类 | 「3步搞定年终总结汇报」         | 有专业技能者 | 高         |
| 对比分析类 | 「A方法和B方法到底选哪个」      | 有实践经验者 | 中高       |
| 避坑指南类 | 「新手做小红书千万别犯这5个错」 | 有踩坑经验者 | 极高       |
| 个人故事类 | 「我从月薪5千到年薪50万的路」   | 有鲜明经历者 | 中         |
| 工具方法类 | 「我用这个表格管理全年项目」    | 有实用工具者 | 高         |

## 二、标题：决定80%点击率的关键

标题是笔记的门面。用户刷到100条内容，可能只会点开3-5条——**全靠标题决定**。

### 2.1 爆款标题的5种万能公式

#### 公式一：数字 + 痛点 + 解决方案

例：「3个方法，让领导再也找不到你加班的理由」

原理：数字降低阅读门槛，痛点引发共鸣，承诺给出希望

#### 公式二：身份标签 + 反差结果

例：「35岁转行做咨询，半年收入翻3倍」

原理：精准筛选目标读者，反差制造好奇心

#### 公式三：否定式 + 颠覆认知

例：「别再逼自己每天早起读书了，这个方法更有效」

原理：打破常识引发好奇，适合有独特见解的内容

#### 公式四：场景 + 情绪 + 行动指令

例：「被同事甩锅怎么办？记住这句话，体面反击」

原理：具体场景代入感强，情绪触发行动欲

#### 公式五：清单式 + 价值承诺

例：「收藏这篇就够了！职场新人第一年必知的12件事」

原理：强调"一站式"价值，促使用户收藏

### 2.2 标题避坑清单

| ❌ 不要这样写         | ✅ 应该这样写                          | 原因                                 |
| :------------------- | :------------------------------------ | :----------------------------------- |
| 「今天分享一点心得」 | 「3个让我少走弯路的职场心得」         | 前者没有信息量，用户不知道值不值得点 |
| 「好书推荐」         | 「这本书让我理解了90%的人际关系问题」 | 前者太泛，后者有具体收益承诺         |
| 「我的创业故事」     | 「裸辞创业第一年，我亏掉了全部积蓄」  | 前者平淡无奇，后者有冲突和悬念       |
| 超过20字的长标题     | 控制在14-18字之间                     | 过长会被折叠，关键信息放前面         |

### 2.3 标题优化自检表

写完标题后，逐项检查：

1. 是否包含至少一个**数字**或**具体信息**？
2. 是否能让人一眼看出**这篇文章解决了什么问题**？
3. 是否避免了**空洞的形容词**（如"很好用"、"强烈推荐"）？
4. 是否有**情绪张力**（好奇、焦虑、共鸣、惊喜）？
5. 是否控制在**14-20个字**以内？

## 三、第一篇文章：如何拿到初始流量

第一篇文章极其重要——它决定了算法对你的**初始标签判定**。发错了方向，后面很难纠正。

### 3.1 首发策略

| 策略               | 具体做法                                           | 目的                 |
| :----------------- | :------------------------------------------------- | :------------------- |
| 选确定性最高的选题 | 选你已经验证过有搜索量的词，不要试新方向           | 确保基础流量         |
| 发布时间选择       | 工作日 7:00-9:00 或 12:00-13:00 或 20:00-22:00     | 用户活跃高峰期发布   |
| 前30分钟运营       | 发布后主动分享给朋友，争取前30分钟内获得5-10个互动 | 触发算法的初始推荐   |
| 带上精准话题标签   | 3-5个标签：1个大类目标签 + 2-3个细分标签           | 帮助算法识别内容归属 |
| 回复每一条评论     | 发布后2小时内回复所有评论，增加互动权重            | 提升互动率指标       |

### 3.2 第一篇笔记的结构建议

推荐选择**清单式/盘点类**内容作为首发，因为这类内容：

- 信息密度高，用户容易获得"获得感"
- 收藏率高，而收藏是小红书算法的重要加权指标
- 生命周期长，搜索流量持续不断

## 四、实操任务

1

#### 建立你的选题词库

用Excel或笔记本，完成以下操作：

- 在小红书搜索框中输入3个你领域的核心词
- 记录每个核心词下方的10个联想词
- 逐一搜索这些联想词，标注搜索结果数量和前排笔记的平均点赞量
- 选出**搜索量高但竞争低**的5个词，这就是你的首批选题

**输出物：**一份包含至少15个选题词的表格

2

#### 为每个选题写5个标题

从上面选出的5个选题中，对**每一个选题**分别用不同的公式写5个标题：

- 1个数字+痛点型
- 1个身份标签+反差型
- 1个否定式+颠覆认知型
- 1个场景+情绪型
- 1个清单式+价值承诺型

**输出物：**25个备选标题，从中选出最好的3个

3

#### 完成并发布第一篇笔记

- 从25个标题中选择一个你最满意的
- 按照清单式结构写一篇完整的图文笔记（6-9张图）
- 配图用Canva或稿定设计制作统一风格的封面
- 带上3-5个精准话题标签
- 选择发布时间（建议工作日晚上20:00-22:00）
- 发布后30分钟内，分享给3-5个朋友请求点赞评论
- 发布后2小时内，回复所有评论

**输出物：**一篇成功发布的小红书笔记

4

#### 建立选题储备库

持续维护一个选题储备表，每周补充新选题：

- 列5列：选题词 | 搜索量估算 | 竞争度 | 我的角度 | 优先级
- 每周花15分钟更新，积累到30个选题后再开始批量创作

**输出物：**一个可复用的选题管理表格

## 五、避坑指南

#### 选题与标题的常见误区

1. **自嗨型选题**：写自己感兴趣的，而不是用户想搜的。解决办法：先搜再看，有搜索量才动笔
2. **标题党陷阱**：标题很吸引人，内容却对不上。小红书用户反感"骗点击"，会直接划走并举报
3. **过度追求创意**：标题要的是"准确+吸引力"，不是"文艺+含蓄"。用户没有耐心猜你的意思
4. **忽略搜索词**：标题里不放关键词，笔记就不会出现在搜索结果中。核心关键词必须出现在标题或正文前100字内
5. **一篇没流量就放弃**：第一篇文章数据差很正常，关键是从数据中学习。发布后24小时看数据，分析哪个环节出了问题
